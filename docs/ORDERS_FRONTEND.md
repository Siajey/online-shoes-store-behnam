# اتصال فرانت به API سفارش

- لایه‌ی API: `src/features/orders/api.ts` (ثبت، لیست، جزئیات، لغو، و توابع ادمین).
- مبلغ‌ها در mapper از ریال به تومان تبدیل می‌شوند (`rialToToman`).
- ثبت سفارش با هدر `idempotency-key`؛ کلید بین تلاش‌های دوباره‌ی همان درخواست ثابت می‌ماند.
- `expectedTotal` فعلاً فرستاده نمی‌شود چون مبلغ سبد شامل هزینه‌ی ارسال نیست.
- پرداخت: مسیر عمومی پرداخت در قرارداد نیست؛ دکمه‌ی «پرداخت سفارش» غیرفعال است.
- صفحه‌ی ادمین سفارش‌ها هنوز ساخته نشده؛ فقط توابع API آماده‌اند.
